# 🤖 SmartQuant Studio / 量化分析智能助手

基于 **MCP (Model Context Protocol)** 架构打造的智能化量化分析与 GUI 控制系统。

传统量化工具通常需要手动输入股票代码、繁琐配置均线参数与图表组件。本项目引入了**自然语言交互引擎**，让你可以像与助手对话一样，通过一句简单的口语指令直接完成标的切换、行情查看与策略指标配置。

---

## ✨ 核心特性

- 🗣️ **自然语言驱动 GUI**：无需手动寻找输入框或点击按钮，输入自然语言（如 *“查看苹果股票”*、*“切换到特斯拉并查看20日均线”*）即可自动驱动界面状态更新与图表渲染。
- 🔌 **高扩展性 MCP 架构**：采用声明式路由与 Tool Handler 机制，解耦意图解析与业务执行。不仅支持股票标的解析，后续可无缝扩展至本地文件处理、宏观数据抓取及自动化爬虫等场景。
- ⚡ **异步解耦与高灵敏响应**：后台使用独立的 Python `asyncio` 与 `threading` 线程模型处理意图识别与数据加载，确保 GUI 界面永远平滑不卡顿。

---

## 💡 交互体验演示

你可以直接在软件的 AI 对话框中输入自然语言命令：

### 1. 股票标的与行情切换
> **你**：苹果股票啊
> 
> **AI**：📈 [MCP Engine] 已解析标的意图，为您切换至 **AAPL** 行情与分析界面。
> *(界面中的股票代码框自动填入 AAPL，并自动重绘最新的 K 线与行情图表)*

### 2. 多参数联动配置 *(扩展能力)*
> **你**：帮我看看特斯拉，短期均线设为 5，长期均线设为 20
> 
> **AI**：📈 [MCP Engine] 已将标的切换为 **TSLA**，并同步更新均线参数为 MA(5, 20)。

## 🛠️ 架构设计简述

系统的自然语言处理模块基于 **MCP 交互协议** 设计，整体运行流程如下：

```text
[用户输入自然语言]
       │
       ▼
[MCP Client 路由分发器 (MCPClientRouter)]
       │
       ├── 识别为金融量化意图 ──► [Tool: financial_quant_parser]
       │                          │
       │                          └── 数据抓取 & 业务分析
       │
       ▼
[吐出标准 Action 指令集 (Command Pattern)]
       │
       ▼
[GUI 渲染引擎 (Data-Driven View)] ──► 自动更新输入框 & 绘制 K 线图表
