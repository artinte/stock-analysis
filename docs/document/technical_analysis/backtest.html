TECHNICAL ANALYSIS

技术分析

从 K 线与趋势出发，系统学习均线、MACD、KDJ、RSI、 成交量、布林带等常用技术分析工具，并建立一套完整的股票技术分析框架。

股票研究 技术分析 K 线 指标 入门 → 进阶

核心观点： 技术分析不是预测未来价格的工具，而是一种研究 价格、成交量、趋势和市场行为 的方法。 单一指标很少能够独立构成可靠的交易依据， 更合理的方法是结合趋势、量价关系、多个指标以及不同时间周期进行综合判断。

1. 什么是技术分析

技术分析（Technical Analysis）是一种通过研究金融资产的历史价格、 成交量以及价格变化规律，分析市场趋势和投资者行为的方法。

对股票而言，技术分析最基本的输入数据通常包括：

  • 开盘价（Open）
  • 最高价（High）
  • 最低价（Low）
  • 收盘价（Close）
  • 成交量（Volume）
  • 成交额（Amount）

通过这些基础数据，可以进一步计算出均线、MACD、KDJ、RSI、 布林带等技术指标。

技术分析研究的核心问题

实际进行技术分析时，并不是简单地寻找“买入信号”或“卖出信号”， 而应该回答几个更重要的问题：

  1. 当前股票处于上涨、下跌还是震荡状态？
  2. 当前趋势是否具有持续性？
  3. 当前价格处于趋势的什么位置？
  4. 成交量是否支持当前价格变化？
  5. 动能是在增强还是减弱？
  6. 当前上涨或下跌是否出现异常信号？

技术分析的三个核心维度

维度 关注内容 常用工具
趋势 判断上涨、下跌或震荡 MA、趋势线
动能 判断上涨或下跌的力量 MACD、RSI、KDJ
量价 判断价格变化是否得到成交量支持 成交量、成交额

2. K 线与价格行为

K 线是技术分析最基础的数据结构。 一根 K 线通常包含一个交易周期内的开盘价、最高价、最低价和收盘价。

Open = 开盘价
High = 最高价
Low = 最低价
Close = 收盘价

阳线与阴线

当收盘价高于开盘价时，通常称为阳线； 当收盘价低于开盘价时，通常称为阴线。

需要注意的是，K 线颜色本身并不是最重要的信息。 更重要的是价格所处的位置、K 线的连续结构以及成交量变化。

K 线应该怎么看？

不建议孤立地研究某一根 K 线。 一根 K 线只有放到前后价格结构中才有意义。

例如：

  • 上涨趋势中的大阳线，通常说明买方力量较强。
  • 高位放量长上影线，可能意味着上方存在较强抛压。
  • 下跌趋势中的大阴线，通常说明卖方占据主动。
  • 低位缩量横盘，可能说明市场正在等待新的方向。

3. 趋势分析

技术分析最重要的基础之一就是趋势。

市场通常可以简单分为三种状态：

市场状态 价格特征 主要关注
上升趋势 高点不断抬高，低点不断抬高 回调、支撑、趋势持续性
下降趋势 高点不断降低，低点不断降低 反弹压力、趋势是否结束
横盘震荡 价格在一定区间内反复波动 区间支撑、压力和突破

为什么趋势如此重要？

因为很多技术指标在不同市场环境下会产生完全不同的效果。

例如，在明显上涨趋势中，RSI 长时间处于较高位置， 并不意味着股票马上就会下跌。 相反，它可能说明市场具有较强动能。

因此：

  • 趋势市场中，应更加重视趋势指标。
  • 震荡市场中，可以更加关注超买超卖指标。
  • 突破行情中，应重点观察价格与成交量是否同步。

4. 移动平均线 MA

移动平均线（Moving Average，MA）是最基础也是最重要的技术指标之一。

它通过计算一定周期内的平均价格， 将短期价格波动进行平滑，从而帮助投资者观察市场趋势。

4.1 简单移动平均线 SMA

最常见的移动平均线是简单移动平均线。

MA(n) = （最近 n 个交易日收盘价之和） ÷ n

例如 MA20，就是最近 20 个交易日收盘价的平均值。

4.2 常见均线

均线 常见用途 特征
MA5 短期趋势 对价格变化非常敏感
MA10 短期趋势 比 MA5 更平滑
MA20 短中期趋势 常用于观察一个月左右的交易趋势
MA60 中期趋势 常用于判断中期趋势
MA120 中长期趋势 对短期波动不敏感
MA250 长期趋势 常被视为年度级别趋势参考

4.3 均线怎么看？

观察均线时，可以重点关注三个方面：

  1. 股价与均线的位置关系
  2. 均线本身的方向
  3. 不同周期均线之间的关系
股价站上均线

如果股价从均线下方重新站上均线， 说明短期价格重新获得一定支撑。

均线向上

如果 MA20、MA60 等中期均线持续向上， 通常说明对应周期的价格趋势偏强。

均线多头排列

例如短期均线位于中期均线上方， 中期均线又位于长期均线上方， 并且各条均线同时向上， 可以认为市场处于较明显的多头结构。

4.4 金叉与死叉

当短期均线向上穿越长期均线时， 通常称为“金叉”； 当短期均线向下穿越长期均线时， 通常称为“死叉”。

但是，金叉和死叉并不是独立的买卖信号。 因为均线本身具有滞后性， 趋势发生之后均线才会逐渐发生变化。

注意： 越短周期的均线越敏感，但假信号越多； 越长周期的均线越稳定，但反应越慢。 实际使用时需要在灵敏度和稳定性之间进行平衡。

5. MACD

MACD（Moving Average Convergence Divergence） 是最常用的趋势与动能指标之一。

MACD 的核心思想是： 通过比较不同周期指数移动平均线之间的关系， 判断市场趋势和动能变化。

5.1 MACD 的三个核心组成

  • DIF：快线
  • DEA：慢线，也称 Signal
  • MACD Histogram：柱状图

5.2 DIF

DIF = EMA(12) - EMA(26)

EMA 是指数移动平均线。 与简单移动平均线相比，EMA 对近期价格给予更高权重。

5.3 DEA

DEA = DIF 的 9 日 EMA

DEA 对 DIF 进行再次平滑， 因此 DIF 和 DEA 的交叉关系可以用于观察短期趋势变化。

5.4 MACD 柱

MACD = 2 × (DIF - DEA)

不同软件对 MACD 柱的具体显示方式可能有所不同， 因此在比较数据时应注意公式和参数设置。

5.5 MACD 金叉

当 DIF 从下方向上穿过 DEA 时， 通常称为 MACD 金叉。

如果金叉同时发生在零轴上方， 通常意味着市场中期趋势已经相对较强。

5.6 MACD 死叉

当 DIF 从上方向下穿过 DEA 时， 通常称为 MACD 死叉。

如果死叉发生在零轴下方， 通常意味着市场整体趋势偏弱。

MACD 状态 常见含义
DIF > DEA 短期动能相对较强
DIF < DEA 短期动能相对较弱
DIF、DEA > 0 整体趋势偏强
DIF、DEA < 0 整体趋势偏弱

5.7 MACD 背离

背离是 MACD 非常重要的应用。

例如：

  • 股价创出新高，但 MACD 没有创出新高， 可以称为顶部背离。
  • 股价创出新低，但 MACD 没有创出新低， 可以称为底部背离。

背离并不意味着趋势一定立即反转， 它更适合被理解为： 当前趋势的动能可能正在减弱。

6. KDJ

KDJ 是一种典型的摆动指标， 常用于观察价格在近期波动区间中的相对位置。

KDJ 包括：

  • K 值
  • D 值
  • J 值

6.1 KDJ 的基本思想

KDJ 的核心是 RSV（Raw Stochastic Value）。

RSV = (Close - Lowest Low) ÷ (Highest High - Lowest Low) × 100

也就是说， 它试图回答一个简单的问题：

当前收盘价位于最近一段时间价格区间的什么位置？

6.2 K、D、J 的关系

K 和 D 是经过平滑处理的随机指标， J 则进一步放大 K 与 D 的差异。

因此 J 值的波动通常比 K、D 更明显。

6.3 超买与超卖

在传统技术分析中， KDJ 高位通常被视为超买区域， 低位通常被视为超卖区域。

但“超买”并不等于“马上下跌”， “超卖”也不等于“马上上涨”。

在强趋势市场中， 指标可能长时间处于高位或低位。

6.4 KDJ 金叉与死叉

K 线上穿 D 线通常称为金叉， K 线下穿 D 线通常称为死叉。

KDJ 更适合用于震荡行情和短周期分析， 不宜单独用来判断长期趋势。

7. RSI

RSI（Relative Strength Index，相对强弱指标） 是另一种非常常见的动量指标。

RSI 主要用于衡量一段时间内上涨力量与下跌力量之间的相对强弱。

7.1 RSI 的基本范围

RSI 通常位于 0 到 100 之间。

RSI 区间 常见解释
70 以上 传统意义上的高位 / 超买区域
50 附近 多空力量相对平衡
30 以下 传统意义上的低位 / 超卖区域

7.2 RSI 为什么会有效？

因为价格上涨和下跌的速度， 本身就是市场动能的一种表现。

如果近期上涨幅度明显大于下跌幅度， RSI 会逐渐提高； 如果近期下跌力量明显增强， RSI 会逐渐下降。

7.3 RSI 的正确理解

不要简单地认为：

RSI > 70 = 卖出

RSI < 30 = 买入

更合理的理解是：

  • RSI 高位：市场短期动能较强，同时需要关注过热风险。
  • RSI 低位：市场短期动能较弱，同时关注超跌可能。
  • RSI 长时间高位：可能说明趋势非常强，而不是马上见顶。
  • RSI 长时间低位：可能说明趋势非常弱，而不是马上反弹。

7.4 RSI 背离

RSI 同样可以观察价格与动能之间的背离。

如果股价持续创出新高， RSI 却没有同步创新高， 说明上涨动能可能正在减弱。

8. 成交量分析

如果说价格告诉我们“发生了什么”， 那么成交量可以帮助我们理解“市场参与程度如何”。

8.1 放量上涨

价格上涨同时成交量明显增加， 通常说明市场参与度提高， 当前上涨得到更多资金参与。

但放量上涨并不意味着一定继续上涨， 高位巨量也可能意味着资金开始分歧。

8.2 缩量上涨

价格上涨但成交量没有明显增加， 可能意味着卖方抛压较小。

在某些上涨趋势中， 缩量回调甚至可能属于正常的趋势调整。

8.3 放量下跌

下跌过程中成交量明显放大， 通常说明卖方力量较强， 应当更加关注趋势是否发生变化。

8.4 缩量下跌

缩量下跌说明成交意愿下降， 但不能简单理解为“马上反弹”。

技术分析中的一个重要原则：

不要只看价格，也不要只看成交量。 更重要的是观察价格与成交量之间是否匹配。

9. 布林带 BOLL

布林带（Bollinger Bands）是一种同时研究趋势和波动率的指标。

它通常由三条线组成：

  • 中轨
  • 上轨
  • 下轨
中轨 = MA(n)

上轨 = 中轨 + k × 标准差

下轨 = 中轨 - k × 标准差

9.1 布林带收窄

当上下轨之间的距离明显缩小时， 说明近期价格波动率下降。

市场可能进入整理阶段， 后续出现较明显价格波动的概率可能增加。

9.2 布林带扩张

当上下轨快速扩大时， 通常说明价格波动正在增加。

但扩张本身并不决定上涨还是下跌， 方向仍然需要结合价格和成交量判断。

10. 指标背离

背离是技术分析中非常重要，但也最容易被误解的概念之一。

所谓背离， 是指价格走势与某个技术指标的走势出现不一致。

顶部背离

例如：

  • 股价创出新高
  • MACD 没有创出新高
  • RSI 没有创出新高

这可能意味着价格虽然继续上涨， 但内部动能正在减弱。

底部背离

如果股价创出新低， 但 MACD 或 RSI 没有同步创新低， 则可能说明下跌动能正在减弱。

重要： 背离不是反转确认。 背离出现以后，价格仍然可能继续沿原方向运行。 因此最好等待价格结构、成交量或其他指标进一步确认。

11. 多指标组合分析

实际投资中，不建议把所有指标同时打开。 指标太多反而容易造成信息冲突。

更合理的方法是： 让不同指标承担不同任务。

分析问题 推荐工具
当前趋势是什么？ MA、MACD
趋势是否有动能？ MACD、RSI
短期是否过热？ RSI、KDJ
当前上涨是否有量？ 成交量
当前波动率如何？ BOLL

一个简单的组合框架

01
先看趋势

使用 MA20、MA60 等判断中短期趋势。

02
再看动能

使用 MACD 判断趋势动能是否增强或减弱。

03
再看量价

判断上涨或下跌是否得到成交量支持。

04
最后观察短期状态

使用 RSI、KDJ 判断短期是否过热或超跌。

12. 不同时间周期分析

同一只股票，在不同时间周期上的技术形态可能完全不同。

因此技术分析不能脱离时间周期。

周期 适合观察 特点
1分钟 / 5分钟 极短期价格行为 噪声非常多
15分钟 / 30分钟 短线趋势 适合观察日内结构
60分钟 短中期趋势 介于日线和日内之间
日线 中短期趋势 最常见的股票分析周期
周线 中长期趋势 过滤大量短期噪声
月线 长期趋势 更适合长期投资研究

多周期分析

一个比较实用的方法是：

大周期决定方向，小周期寻找位置。

例如先通过周线判断长期趋势， 再通过日线判断中期趋势， 最后通过 60 分钟或更短周期观察短期价格结构。

13. 一个完整的技术分析流程

如果面对一只股票，不知道应该从哪里开始， 可以按照下面的顺序进行分析。

01
判断大趋势

先看周线和日线，判断股票处于上涨、下跌还是震荡阶段。

02
判断均线结构

观察 MA20、MA60、MA120 等均线方向以及多空排列关系。

03
判断 MACD

观察 DIF、DEA、零轴以及柱状图变化。

04
判断成交量

判断价格变化是否得到成交量支持。

05
判断短期动能

使用 RSI、KDJ 等指标观察短期市场状态。

06
寻找关键价格位置

观察前高、前低、成交密集区、均线以及重要支撑压力位置。

07
最后才考虑交易计划

明确自己的持有周期、风险承受范围以及退出条件。

14. 技术分析中的常见误区

误区一：认为指标可以预测未来

技术指标本质上都是根据历史价格和成交量计算出来的。 它们不能直接知道未来发生什么。

因此指标更适合用于：

  • 描述当前市场状态
  • 识别趋势
  • 衡量动能
  • 发现异常变化

误区二：看到金叉就买

金叉只是一个状态变化。 如果市场本身处于长期下跌趋势， 短周期金叉可能只是一次反弹。

误区三：RSI 超买就卖

强势股票可以长时间保持高 RSI。 超买说明价格动能较强， 而不是保证价格马上下跌。

误区四：指标越多越准确

MACD、KDJ、RSI 等指标虽然名称不同， 但很多指标都来自价格数据。

如果同时使用十几个指标， 并不意味着拥有十几个独立的信息源。

更好的方法是选择功能互补的指标。

误区五：忽视市场环境

牛市、熊市、震荡市场中， 同一个指标的表现可能完全不同。

因此技术指标必须放在具体市场环境中理解。

15. 技术分析与基本面分析

技术分析和基本面分析并不是互相排斥的两套体系。

它们回答的问题不同。

分析方式 核心问题 常见数据
技术分析 市场现在怎么走？ 价格、成交量、技术指标
基本面分析 企业值多少钱？ 营收、利润、现金流、资产、估值
量化分析 历史数据中是否存在可重复的规律？ 因子、价格、财务、交易数据

对长期投资者而言， 技术分析可以用于研究价格趋势和买卖时机， 基本面分析则可以用于判断企业质量和估值。

一个更加完整的研究框架可以是：

基本面决定“研究什么”， 估值决定“价格是否合理”， 技术分析帮助理解“市场正在怎么交易”。

16. 进一步学习：量化技术分析

当掌握基本技术指标以后， 可以进一步进入量化分析阶段。

与人工观察不同， 量化分析会将技术指标转换成可以计算和回测的规则。

例如均线策略

IF MA20 > MA60
→ 趋势状态 = Bullish

IF MA20 < MA60
→ 趋势状态 = Bearish

再例如 MACD：

IF DIF > DEA AND DIF > 0
→ 动能状态 = Strong

然后可以进一步将这些条件组合起来， 构建因子、选股策略和回测模型。

17. 技术分析总结

  • MA： 主要用于判断趋势和价格的平均成本变化。
  • MACD： 主要用于研究趋势和动能变化。
  • KDJ： 主要用于观察短期价格位置和超买超卖状态。
  • RSI： 主要用于衡量价格动量和相对强弱。
  • 成交量： 用于观察市场参与程度以及量价关系。
  • BOLL： 用于观察价格波动率和价格相对位置。
  • 背离： 用于观察价格与动能之间的不一致。

真正的技术分析并不是寻找一个“神奇指标”， 而是建立一套结构化的观察方法。

一个比较完整的分析逻辑可以概括为：

趋势 → 价格结构 → 均线 → 动能 → 成交量 → 支撑与压力 → 多周期确认 → 风险管理

当这些信息相互验证时， 技术分析的参考价值通常会高于单独依赖某一个指标。
