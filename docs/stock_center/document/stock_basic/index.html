STOCK BASICS

股票基础

从零开始建立股票投资知识体系。 本课程不以“推荐股票”为目标，而是帮助你理解股票是什么、 股票市场如何运行、公司如何创造利润，以及投资者应该如何分析一家公司。

COURSE OVERVIEW

这套课程学什么？

很多人开始投资股票时，第一件事就是寻找“哪只股票会涨”。 但真正长期有效的投资能力，并不是记住几个股票代码， 而是建立一套能够重复使用的分析方法。

这套股票基础课程按照 股票 → 市场 → 公司 → 财务 → 估值 → 投资 的顺序展开。 你可以把它理解为一条完整的股票投资入门路线。

学习目标 学完 14 篇文章后，你至少应该能够看懂一只股票的基本信息、 理解价格涨跌的基本逻辑、阅读主要财务指标， 并知道如何进一步开展一家公司的投资研究。

STUDY METHOD

建议这样学习

不建议一次把 14 篇文章全部读完。 股票投资真正需要的是理解，而不是记忆。

01

先理解，再记指标

不要一开始就背 PE、PB、ROE。 先理解这些数字究竟在描述什么。

02

用真实公司练习

学完一个概念以后， 尝试在真实上市公司上寻找对应的数据。

03

不要预测每一次涨跌

投资分析的重点不是预测明天涨还是跌， 而是理解企业价值和风险。

04

建立自己的分析框架

最终目标不是记住文章内容， 而是形成一套可以重复使用的研究流程。
