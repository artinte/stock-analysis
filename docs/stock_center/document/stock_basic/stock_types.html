LESSON 03 · STOCK BASICS

股票的分类

股票并不是只有一种形式。 不同市场、不同股权结构以及不同公司的经营特征， 会形成不同类型的股票。 理解这些分类，可以帮助我们建立更加完整的股票认知体系。

一、为什么要给股票分类？

当我们开始接触股票之后，很快就会遇到很多不同的名称。

例如： A 股、港股、美股、普通股、优先股、 蓝筹股、成长股、价值股、周期股、防御股。

这些名称看起来很复杂， 但实际上它们是在从不同角度描述股票。

有些分类描述的是股票在哪里交易， 有些描述的是股东拥有什么权利， 还有一些描述的是公司的经营特征和投资属性。

一个重要原则：

股票分类不是互相排斥的。 同一家公司可以同时属于多个类别。

例如，一家公司可能是 A 股上市公司， 同时属于蓝筹股，也可能属于价值股。

二、按照交易市场分类

最容易理解的一种分类方式， 是按照股票在哪个资本市场交易来划分。

对普通投资者来说， 最常见的三个市场就是： A 股、港股和美股。

1. A 股

A 股通常指中国内地股票市场中的人民币普通股票。 主要交易场所包括上海证券交易所、深圳证券交易所和北京证券交易所。

我们平时看到的贵州茅台、工商银行、 宁德时代、比亚迪等股票， 都属于 A 股市场中的股票。

A 股市场拥有数量非常庞大的上市公司， 覆盖金融、消费、医药、科技、制造、能源、 公用事业等众多行业。

2. 港股

港股通常指在香港交易所上市交易的股票。

一些中国内地企业会选择同时在内地和香港上市， 因此我们会看到所谓的 A+H 股。

例如，一家公司可能在 A 股市场有一个股票代码， 同时在香港市场也有一个股票代码。

虽然背后可能是同一家企业， 但两个市场的交易规则、投资者结构、 估值水平和交易货币都可能不同。

3. 美股

美股通常指美国股票市场中的股票。 常见交易场所包括纽约证券交易所和纳斯达克等。

苹果、微软、英伟达、亚马逊等知名公司， 都是美国股票市场中的上市公司。

美股市场在科技公司、创新型企业、 全球化大型企业方面具有非常丰富的代表性。

注意：

A 股、港股、美股并不是在描述公司的行业， 而是在描述股票的交易市场。

同一家公司甚至可能在不同市场同时上市。

三、A 股、港股和美股有什么不同？

初学者很容易认为： “股票就是股票，在哪里交易应该都差不多。”

实际上，不同市场之间存在明显差异。

交易货币

A 股主要使用人民币， 港股主要使用港币， 美股主要使用美元。

投资者结构

不同市场中的个人投资者、机构投资者、 海外投资者占比不同。

交易制度

不同市场在交易时间、涨跌幅、 交收制度和卖空机制等方面存在差异。

估值体系

相同类型的公司在不同市场中， 可能存在不同的估值水平。

因此，在比较股票时， 不能只看公司名称和股票价格。

还需要明确： 这家公司在哪个市场上市？

四、什么是普通股？

从股东权利的角度来看， 最常见的一类股票是普通股。

我们日常在证券市场中交易的大多数股票， 本质上都属于普通股。

普通股股东通常拥有以下基本权利：

✓ 参与公司利润分配
✓ 参加股东大会
✓ 依法行使表决权
✓ 在公司清算时享有剩余财产权益

但是需要特别注意： 拥有股票，并不意味着每年一定可以拿到股息。

公司是否分红、分多少， 通常取决于公司的盈利能力、 现金状况、发展阶段以及董事会和股东大会等相关程序。

因此，股票投资收益通常来自两个主要方向：

第一部分：股价上涨带来的资本利得。

第二部分：公司分红带来的股息收益。

五、什么是优先股？

与普通股相比， 优先股是一种具有特殊权利安排的股票。

“优先”主要体现在某些权利顺序上， 例如在特定情况下， 优先股股东可能在股息分配或剩余财产分配方面 享有优先于普通股股东的权利。

但优先股的具体权利并不意味着它在所有方面都优先。

例如某些优先股在表决权方面可能受到限制， 具体权利需要根据发行条款判断。

初学者可以这样理解：

普通股更强调对公司剩余收益和成长的参与； 优先股则通常更强调特定收益和分配顺序。

对普通投资者而言， 日常接触最多的仍然是普通股。

六、什么是蓝筹股？

“蓝筹股”并不是一种法律意义上的股票类别， 而是一种市场习惯上的称呼。

通常来说， 蓝筹股指规模较大、经营相对成熟、 行业地位较强、盈利能力相对稳定的上市公司。

很多大型银行、能源公司、 消费公司和行业龙头， 都可能被市场称为蓝筹股。

蓝筹股通常具有一些共同特征：

公司规模较大

通常具有较大的营业规模和市值。

行业地位较高

在所在行业中往往具有较强的竞争地位。

经营相对成熟

商业模式经过较长时间验证。

盈利相对稳定

相比早期成长型公司， 盈利波动通常相对较低。

但需要注意： 蓝筹股并不等于一定会上涨。

一家优秀的大公司， 如果买入价格过高， 仍然可能成为一笔不理想的投资。

七、什么是成长股？

成长股通常指那些未来仍然具有较大发展空间， 收入、利润、用户或者市场份额可能保持较快增长的公司。

成长股的核心并不是“现在赚多少钱”， 而是市场更加关注： 公司未来能够成长到什么规模。

比如一家科技公司当前利润可能并不算特别高， 但如果市场认为它未来能够进入一个巨大的新市场， 投资者可能愿意给予较高估值。

因此，成长股经常具有以下特点：

✓ 收入增长速度较快
✓ 市场空间较大
✓ 产品或技术具有扩张潜力
✓ 市场份额可能持续提升
✓ 投资者对未来预期较高

但成长股也有一个非常明显的问题： 预期越高，对未来业绩的要求也越高。

如果公司未来增长低于市场预期， 即使公司仍然在赚钱， 股票价格也可能下跌。

这是理解成长股非常重要的一点：

股票价格反映的不是今天的成绩单， 而是市场对未来的定价。

八、什么是价值股？

价值股通常指市场价格相对于公司基本面价值 看起来比较便宜的股票。

投资者在分析价值股时， 经常会关注：

✓ 市盈率 PE
✓ 市净率 PB
✓ 股息率
✓ 公司现金流
✓ 公司资产质量
✓ 长期盈利能力

价值投资的核心思想之一， 是寻找价格与内在价值之间的差异。

例如： 如果一家公司的盈利能力比较稳定， 资产质量较好， 但是市场因为短期原因给予了较低估值， 一些投资者可能认为它具有投资价值。

但是：

“便宜”不等于“有价值”。

一家公司 PE 很低， 可能是因为市场认为它未来的利润会下降。

所以判断价值股， 不能只看一个估值指标。

九、什么是周期股？

周期股通常指公司盈利能力与经济周期、 商品价格或者行业供需关系高度相关的股票。

常见的周期性行业包括： 钢铁、有色金属、煤炭、石油化工、 航运、部分机械设备等。

这些行业的一个典型特点是： 行业景气度会发生明显变化。

当商品价格上涨、需求旺盛时， 企业利润可能快速增长。

当需求下降、产能过剩或者商品价格下跌时， 企业利润又可能快速下降。

因此分析周期股时， 不能只看当前利润。

更重要的是判断： 当前处于周期的什么位置？

景气上行

产品价格上涨，需求改善， 企业盈利增加。

景气高点

盈利可能达到很高水平， 但行业扩产也可能增加。

景气下行

需求下降或供给过剩， 企业盈利开始下降。

周期底部

盈利可能处于低位， 行业开始等待下一轮复苏。

十、什么是防御股？

防御股通常指业绩受经济周期影响相对较小、 需求比较稳定的公司。

常见的防御型行业包括： 公用事业、部分必需消费品、 医药、通信等。

这些行业提供的很多产品或服务， 即使经济环境不好， 人们仍然存在一定需求。

例如： 人们可能会减少购买高端商品， 但仍然需要基本生活用品； 企业可能减少资本开支， 但社会仍然需要基本的电力、通信等服务。

因此，防御股通常更强调： 盈利稳定性、现金流和股息。

当然，“防御”并不意味着没有风险， 更不意味着股价不会下跌。

十一、大盘股、中盘股和小盘股

股票还可以按照公司市值大小进行分类。

1. 大盘股

大盘股通常指市值较大的上市公司。 这些公司往往已经发展到比较成熟的阶段， 在行业中拥有较高的市场影响力。

2. 中盘股

中盘股的公司规模处于中间位置。 一部分公司已经形成稳定业务， 同时仍然拥有较大的成长空间。

3. 小盘股

小盘股通常指市值较小的上市公司。 其中可能存在快速成长的企业， 也可能存在经营能力较弱、风险较高的企业。

不要把市值大小直接等同于投资价值。

大盘股不一定比小盘股更值得投资， 小盘股也不一定成长更快。

市值只是帮助我们认识公司的一个维度。

十二、不同类型的股票可以同时存在

到这里，可能会出现一个问题：

一家公司到底是蓝筹股， 还是成长股？ 是价值股， 还是周期股？

实际上，它们并不是互相排斥的标签。

因为这些分类使用的是不同维度。

按市场

A 股、港股、美股。

按股权权利

普通股、优先股。

按公司规模

大盘股、中盘股、小盘股。

按投资风格

成长股、价值股、蓝筹股等。

按经营特征

周期股、防御股等。

因此，一家公司完全可能同时具有多个标签。

例如：

某大型消费公司可能是：

A 股 + 普通股 + 大盘股 + 蓝筹股 + 防御型股票

某科技公司可能是：

A 股 + 普通股 + 大盘股 + 成长股

这些标签并不是公司的正式“身份证”， 而是投资者为了更方便地理解公司而形成的分类方式。

十三、股票分类对投资有什么用？

学习股票分类，并不是为了记住很多名词。

真正的意义是： 帮助我们快速建立对一家公司的第一层认识。

当你看到一家公司时， 可以先问自己几个问题。

✓ 它在哪个市场上市？
✓ 它属于什么行业？
✓ 公司规模大还是小？
✓ 它属于成熟型企业还是成长型企业？
✓ 它的盈利是否具有周期性？
✓ 它的业务是否具有防御属性？
✓ 投资者主要在期待它什么？

最后一个问题尤其重要。

因为不同类型的股票， 市场关注点往往不同。

成长股

更关注未来收入、利润和市场空间。

价值股

更关注估值与公司真实价值之间的关系。

周期股

更关注行业景气度和周期位置。

防御股

更关注盈利稳定性、现金流和股息。

十四、不要只根据“标签”买股票

股票分类非常有用， 但也很容易被误用。

例如： “这是一只成长股，所以应该上涨。”

这种推理是不成立的。

成长股只说明公司的增长预期可能比较高， 并不能保证股票价格上涨。

同样： “这是一只蓝筹股，所以一定安全。”

也不完全正确。

即使是一家非常优秀的大公司， 如果买入价格远远高于合理价值， 投资者仍然可能承担较大的估值风险。

股票分类只是起点，不是投资结论。

分类帮助我们知道“它是什么样的公司”， 但真正的投资分析还需要继续研究： 公司业务、财务状况、竞争优势、 盈利能力、现金流和估值。

十五、从股票分类进入真正的公司分析

到目前为止， 我们已经完成了股票认知的三个基础步骤。

第一步

股票是什么？

第二步

股票和公司是什么关系？

第三步

股票可以分成哪些类型？

下一步就应该开始回答一个更加重要的问题：

一家上市公司到底应该怎么看？

因为投资股票最终并不是在比较一串代码， 而是在判断一家企业。

我们需要逐渐从：

股票代码 → 股票价格 → 股票类型 → 行业 → 公司 → 财务 → 盈利 → 竞争优势 → 估值

这也是整个股票研究体系逐渐建立起来的过程。

十六、本篇总结

股票分类看起来只是一些基础概念， 但它实际上是理解股票市场的重要工具。

本篇需要掌握的核心内容包括：

✓ A 股、港股、美股属于不同股票市场。
✓ 普通股和优先股主要区别在股东权利安排。
✓ 蓝筹股通常代表规模较大、经营成熟的公司。
✓ 成长股更加关注未来增长空间。
✓ 价值股更加关注价格与公司价值之间的关系。
✓ 周期股的盈利容易受到经济和行业周期影响。
✓ 防御股通常具有相对稳定的需求和盈利。
✓ 大盘股、中盘股、小盘股是按照公司规模进行的分类。
✓ 一家公司可以同时拥有多个股票分类标签。
✓ 股票分类只是分析的起点，不是投资结论。

真正成熟的股票研究， 不是看到“成长股”“蓝筹股”这样的标签就做出决定， 而是进一步理解这些标签背后的企业。
