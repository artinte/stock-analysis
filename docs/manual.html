序章：被狂热与冷落撕裂的通信板块

2025年12月，A股交易大厅的空气仿佛要被煮沸。

散户老张紧盯着自选股界面，呼吸急促。以“易中天”三巨头——中际旭创、新易盛、天孚通信为首的光模块板块，在 AI 算力浪潮的狂推之下节节攀升。这些股票的市盈率（PE）动辄炒到了上百倍，带动着整个通信 ETF（515880）一路高歌猛进。

“老陈，冲不冲？再不买就来不及了！”老张拍着旁边程序员出身的投资者老陈的肩膀。

老陈没有说话，伸手打开了自己的笔记本电脑，终端窗口里正运行着他自研的开源分析工具 Stock Analysis。

“别急。”老陈推了推眼镜，“你只看到了大热的红花，却忽略了被大众遗忘的绿叶。”

老陈在终端敲入几行代码。屏幕上立刻弹出了同处于通信板块的亨通光电（600487）与中天科技（600522）的数据剖析：

terminal — stock_analysis_env
# 查看通信板块内成分股的估值与 ETF 持仓渗透率
from stock_analysis import SectorAnalyzer, ETFHoldingsTracker

“看到没有？”老陈指着屏幕，“此时亨通光电的 PE 才 17 倍，股价不过 20 元出头。市场把注意力全押在光模块上，却无视了同样受受益于算力网建设的海缆与光纤龙头。ETF 的机构资金一直在暗中吃筹码。”

半年后，事实证明了系统的敏锐——亨通光电股价在随后的行情中一路走高，最高较当时翻了近 6 倍。

“这就是**买卖股票的研究维度**。”老陈转过头对老张说，“今天我就拿当前半导体设备热门股北方华创（002371）为例，带你走一遍 Stock Analysis 的完整二十六维评估流程。”

第一章：定位血统——行业归属与 ETF 阵营

“分析的第一步，不能只看名字。”老陈在键盘上飞速敲击，“首先得获取公司名称并精确定位它的行业层次。”

1_industry_classification.py
from stock_analysis.industry import get_stock_industry_category, get_stock_etf_holdings

# 1. 获取股票所处的行业（一二三四级）
industry_hierarchy = get_stock_industry_category(symbol="002371.SZ")
print("【行业分类】:", industry_hierarchy)
# 输出: 电子(一级) -> 半导体(二级) -> 半导体设备(三级) -> 刻蚀与薄膜沉积设备(四级)

# 2. 探查关联 ETF 与机构动向（ETF 通常代表公募基金，这是极易被忽略但至关重要的指标）
etf_data = get_stock_etf_holdings(symbol="002371.SZ")
for etf in etf_data[:3]:
    print(f" - ETF: {etf.name}({etf.code}), 持仓占比: {etf.weight}%, 净买入趋势: {etf.flow_trend}")
老张：“直接看它是半导体不就行了，干嘛分这么细？”
老陈：“一级行业看大势，四级行业看壁垒。半导体里的设计、封测和设备在周期上截然不同。结合 get_stock_etf_holdings，你能一眼看出哪些公募基金在用真金白银为你锁仓。”

第二章：宏观与行业周期审计（维度 1 ~ 5）

老陈接着调出了系统中的宏观与行业分析引擎。终端界面开始按顺序输出针对北方华创的评估：

2_macro_and_industry_analysis.py
from stock_analysis.macro import MacroEngine, IndustryCycleEngine

macro = MacroEngine(symbol="002371.SZ")
cycle = IndustryCycleEngine(symbol="002371.SZ")

# 行业是上行还是下行
print("【行业趋势】:", cycle.get_industry_trend()) 
# 输出: 扩张期（受益于国内晶圆厂扩产周期）

# 技术壁垒与蓝海属性
print("【技术壁垒】:", cycle.get_tech_barrier_score())  # 得分: 9.5/10 (高专利密度/研发护城河)
print("【蓝海/红海】:", cycle.is_blue_ocean_market())     # 输出: 局部蓝海 (高阶刻蚀设备国产化率不足30%)

# 行业周期位置
print("【行业周期阶段】:", cycle.get_current_phase())   # 输出: 逆周期投资上升期

“如果一个行业整体在下行，哪怕公司再优秀也难以对抗时代。”老陈解释道，“北方华创所处的半导体设备领域，技术壁垒极高，且处于典型的国产替代蓝海增长期。”

第三章：公司基本面与护城河深挖（维度 6 ~ 10）

紧接着进入了最核心的财报与经营指标穿透阶段。老陈启动了公司的基本面分析模块：

from stock_analysis.fundamentals import FinancialAuditor

第四章：隐藏风险与安全边际排雷（维度 11 ~ 15）

“很多散户买股票只看暴涨空间，却不看爆雷风险。”老陈的面色变得严肃，“Stock Analysis 专门设计了安全审计模块，用来排查可转债、质押率以及管理层资质。”

4_risk_and_governance.py
from stock_analysis.risk import RiskAuditor

risk = RiskAuditor(symbol="002371.SZ")

# 11. 可转债额度与质押比例

# 12. 公司的全球化水平
print("【海外业务收入占比】:", risk.get_globalization_index()) # 输出: 8.5% (主战场在国内，受海外直接监管风险较低)

# 13. 公司领导层水平

# 14. 汇率变化影响
print("【汇率敏感度分析】:", risk.get_fx_sensitivity()) # 美元/人民币汇率波动对毛利率的影响控制在 1.5% 内

# 15. 全球宏观环境与不可控因素 (战争、地缘政治)

# 输出: 高关注度 (受实体清单及出口管制政策影响明显，但催化自主可控需求)
