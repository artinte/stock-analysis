# Stock Valuation Model Architecture ｜ 股票估值模型架构说明

本项目致力于构建一个工业级的金融量化与股票估值系统。通过将历史财务主数据、纯财务衍生指标与高频市场估值指标进行**三层解耦**设计，实现高并发、低延迟的量化回测与选股数据支撑。

---

## 📌 核心逻辑：三表底座与衍生双翼

在量化金融体系中，财务三张表是客观的**“历史输入端”**，而财务指标与估值指标则是层层递进的**“动态衍生计算端”**。整个系统由这五大核心模块共同构成了最稳固的**“铁三角 + 双翼”**架构。
